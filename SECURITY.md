# Security policy

## Supported version

Security fixes are provided for the latest version on the `main` branch.

## Reporting a vulnerability

Please use GitHub Private Vulnerability Reporting:

<https://github.com/CrystalSight/astrbot_plugin_jx3tools/security/advisories/new>

Do not open a public issue for a suspected vulnerability. Never include a real
JX3API Token, Ticket, chat transcript, user identifier, private image, or server
configuration in a report. Use synthetic examples and redact logs before
attaching them.

Include the affected version, reproduction prerequisites, reachable code path,
expected impact, and a minimal proof of concept when safe to do so. The
maintainer will acknowledge the report through GitHub and coordinate a fix and
disclosure there.
