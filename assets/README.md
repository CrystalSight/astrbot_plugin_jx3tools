# Optional local game thumbnails

The public repository intentionally does not distribute the JX3BOX-derived PNG
files formerly stored under `adventures/` and `bosses/`. Local copies are ignored
by Git. The existing renderer falls back when an expected file is absent; a
separate visual redesign is deferred to later work.

These images are third-party material and are not covered by this repository's
MIT License. See `../THIRD_PARTY_NOTICES.md` for the license research and exclusion
decision.

Source endpoints and URL rules were verified on 2026-07-19:

- `https://node.jx3box.com/serendipities`
- `https://node.jx3box.com/monster/boss`
- `https://img.jx3box.com/adventure/`
- `https://img.jx3box.com/pve/baizhan/`

The maintenance script documents the historical source mapping, but any local use
must independently satisfy the applicable authorization terms.
