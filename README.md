# JX3Tools

JX3Tools 是一个 AstrBot 剑网 3 查询与实时推送插件。它调用注册表中的固定 JX3API 接口，并使用本地
Pillow 与阿里巴巴普惠体 3 生成适合手机阅读的 720 px 单栏图片；查询数据、文章正文和字体
不会发送给远程图片渲染服务。

本项目是非官方社区项目，与 JX3API、JX3BOX、金山软件、西山居及《剑网 3》运营方不存在
隶属或背书关系。

## 兼容性

- AstrBot：`>=4.26.6,<5`
- Python：`>=3.12`
- 运行依赖：`aiohttp>=3.11,<4`、`Pillow>=12,<13`
- 新版推送需要平台支持 AstrBot 主动消息；QQ 官方 API 平台不支持本插件所用的主动发送接口。

## 功能

- 免费：日常、月历、行侠、科举、新闻、公告、开服、技改、小药。
- 会员：角色、阵眼、奇遇记录、名剑战绩、金价、诛恶、百战、马场、名片、
  角色百战、今日赤兔、本周赤兔、物品搜索、物价、随机名片、秘境方位。
- 其他：骚话、舔狗。
- 免费实时推送：开服状态、官方新闻、版本更新；每群可分别设置区服和开关。
- 新闻、公告和技改支持 10 秒发起者锁定的序号选择；选择后在一个信息框中返回经校验的
  剑网 3 官网链接，空两行后附上一句骚话，不再生成正文图片。
- 名片图片会下载、校验并作为本地图片直接发送，不回复图片 URL。
- 单模式名剑战绩会复用相同区服和角色名获取名片图；名片不可用时自动回退原有战绩布局。
- 月历、小药、奇遇记录、名剑战绩、金价和百战使用各自定制的移动端图片布局。奇遇记录使用
  项目新制的透明水墨名称徽记；百战使用无头像的 10 列蛇形路线。
- 物品搜索会先逐行发送可复制名称；物品搜索和物价仅嵌入通过安全校验的商品图片。

## 安装

在 AstrBot 根目录的 `data/plugins` 下克隆本仓库：

```bash
git clone https://github.com/CrystalSight/astrbot_plugin_jx3tools.git \
  data/plugins/astrbot_plugin_jx3tools
```

AstrBot 会根据 `requirements.txt` 安装运行依赖。重载插件或重启 AstrBot 后，在日志中确认
`astrbot_plugin_jx3tools` 已成功初始化且没有 traceback。

### 安装字体

字体不随本项目分发。请从官方字体包中取得以下两个原始 TTF，并复制到：

```text
AstrBot/data/plugin_data/astrbot_plugin_jx3tools/fonts/
├── AlibabaPuHuiTi-3-55-Regular.ttf
└── AlibabaPuHuiTi-3-75-SemiBold.ttf
```

若 Docker Compose 使用 `./data:/AstrBot/data`，对应宿主机路径为：

```text
<Compose目录>/data/plugin_data/astrbot_plugin_jx3tools/fonts/
```

字体目录位于独立的 `data/plugin_data`，不会随插件源码更新而删除。字体缺失时插件仍可加载，
图片查询会降级为有界文字，并在日志中提示管理员检查字体路径。不要把字体复制到插件源码目录。

## 配置

配置分为通用设置、JX3API 凭据、功能分组、网络与限流、结果展示、事件推送和群组配置。

- `api_base_url` 仅接受不含路径、查询和用户信息的 HTTPS 地址。
- 本版本默认使用当前官方地址 `https://www.jx3api.com`；旧版备份地址会在运行时安全归一化到
  当前主站。
- 免费、会员、其他功能可分别关闭。
- JX3API Token 只发送给明确需要 Token 的接口；Ticket 只发送给明确需要 Ticket 的接口。
- 角色、交易、随机名片和秘境方位等会员功能需要换新后的 Token；阵眼和名剑战绩还需要 Ticket。
  免费功能不携带 Token 或 Ticket。
- Token 和 Ticket 需要由管理员通过 JX3API 的账户或服务渠道取得，不要让聊天用户提供凭据。
- 默认区服只补齐 `server` 参数，聊天用户不能覆盖凭据、URL 或 API 路径。
- `auto` 遵循每个功能的展示设计；`text` 尽量使用文字；`image` 尽量使用图片。开服、秘境方位、
  骚话和舔狗始终使用文字。

AstrBot 将配置保存到：

```text
data/config/astrbot_plugin_jx3tools_config.json
```

该配置文件可能包含 Token/Ticket，不应提交到 Git、附在 Issue 中或发送给第三方。

### 多群配置与推送

AstrBot 的会话配置可以选择可用插件，本插件内部的区服和开关通过“群组配置”管理。
配置保存并重载插件后生效；旧配置无需迁移，未登记的群继续使用全局查询设置，不接收推送。

1. 在目标群发送 `/sid`，取得 UMO 与群 ID。群 UMO 格式为 `平台实例ID:GroupMessage:群ID`，
   例如 `qq_bot:GroupMessage:123456`。开启群内会话隔离时，使用 `/sid` 提示的群 ID 替换 UMO
   中的会话部分，不要填入成员 ID。不同机器人实例必须使用各自的平台实例 ID。
2. 在“群组配置”新增群组，填写备注和群 UMO。最多登记 200 个群；重复或非法目标不会推送，
   日志仅提示对应条目序号。删除条目并重载可取消该群的推送登记。
3. 默认区服填写完整服务器名，例如“梦江南”，不要填写简称或“大区-服务器”。留空继承全局；
   查询显式填写的区服优先于群默认。开服推送仅精确匹配该群有效默认区服，留空时跳过。
4. 查询开关、免费／会员／其他查询分类以及三类推送均可选择“继承全局／开启／关闭”。
   查询关闭不影响推送；关闭其他查询也不影响推送附加骚话。凭据、网络和展示参数全局共享。
5. “事件推送”中的三个全局开关默认关闭，只作为已登记群的默认值。可在群组内单独开启，
   也可在全局开启后为个别群关闭。AstrBot 会话配置还必须允许使用 JX3Tools。

例如：全局默认区服为“梦江南”、新闻推送开启；甲群继承全局，乙群填写“唯我独尊”并关闭新闻。
两群分别开启开服推送后，只会收到自己默认区服的开关服变化，乙群不会收到新闻。

推送通过无凭据的 `wss://socket.nicemoe.cn` 接收，只处理 `2001`、`2002`、`2003`。
每群每条消息单独调用现有 `/saohua/random` 接口；5 秒内失败或无内容时，追加
“骚话暂时走丢了。”。全部发送为一条纯文本，正文与骚话之间空一行，与图片模式无关。

```text
区服：电信一区-梦江南
已开服
时间：2026-09-11 08:00:00

随机骚话
```

```text
标题：新闻标题
链接：https://jx3.xoyo.com/show-3-123-1.html
日期：2026-09-11

随机骚话
```

```text
旧版本
↓  ↓  ↓  ↓
新版本
更新大小：128 MB

随机骚话
```

开服时间显示北京时间；新闻日期直接使用官方 `date`；更新大小保留原始单位。
关闭所有目标的推送开关并重载后不再建立推送连接；在 AstrBot 中禁用整个插件也会停止后台任务。

连接断开后以最长 60 秒的间隔退避重连，不补发离线历史。每群最多排队 100 条，等待超过
10 分钟或队列已满的消息会丢弃，发送间隔至少 2 秒。失败不自动重试，以免结果不明确时重复发送。
按群与消息内容记录发送尝试，24 小时去重记录通过 AstrBot 插件 KV 保存（最多 20,000 条，
超出时淘汰最旧记录），不写入插件源码目录；重载保留记录。记录成功后发生发送失败或进程中断，
同一事件可能被跳过，此机制不保证每条消息必达。

未收到通知时，依次检查群 UMO、群和全局推送开关、AstrBot 的可用插件选择、默认区服全称，
以及平台是否支持主动发送。日志中的连接失败表示无法访问推送服务；存储初始化失败时推送保持
关闭，修复存储后重载；平台不可用和发送失败不会阻塞其他群。消息字段或新闻链接不符合协议时跳过。

## 使用

```text
/jx3 帮助
/jx3 帮助 角色
/jx3 指令 全部
/jx3 指令 会员
/jx3 日常
/jx3 日常 1
/jx3 月历
/jx3 行侠 觅宝会
/jx3 科举 DXTGQYJGX
/jx3 新闻 10
/jx3 角色 梦江南 角色名
/jx3 名片 梦江南 角色名
/jx3 随机名片 梦江南
/jx3 秘境方位
```

帮助中 `<参数>` 表示必填，`[参数]` 表示可选。带空格的参数可以使用引号。

## 网络、数据与隐私

- JX3API 请求限定为管理员配置的 HTTPS 基础地址和插件注册表中的固定当前 API 路径，使用
  POST JSON 且禁用重定向。
- 新闻、公告和技改只发送所选列表项经校验、规范化后的剑网 3 官网 URL，不抓取正文；
  同一信息框中的骚话来自现有免费接口，失败时使用固定降级文案。
- 名片和商品图片只从受信 HTTPS 域名下载，禁用重定向，并限制内容类型、字节数和像素数。
- 连接中断、5xx、空响应和截断 JSON 最多进行三次有界尝试。
- 插件不缓存角色、交易或文章结果，不保存聊天输入，不记录凭据或完整私人数据。
- 本地结果图片写入系统临时目录，并交由 AstrBot 跟踪清理。
- 字体保存在 `data/plugin_data/astrbot_plugin_jx3tools/fonts`；配置保存在 AstrBot 的
  `data/config`，都不写入插件源码目录。

## 故障排查

- **插件加载但图片查询退化为文字**：检查两份字体文件的名称和 `plugin_data` 路径。
- **提示缺少 Token 或 Ticket**：在 AstrBot 插件配置中填写对应凭据；不要在聊天中发送。
- **Token 提示鉴权失败**：在 JX3API 官网完成旧 Token 换新，并检查 Token/Ticket 权限；不要把
  凭据写入 Issue 或日志。
- **JX3API 请求失败**：确认基础地址为 `https://www.jx3api.com` 且不带路径，并检查上游服务
  状态和 AstrBot 日志。
- **更新后仍是旧代码**：确认 Git 工作树已更新并通过 AstrBot 插件管理器重载本插件。

## 徽记资源维护

```bash
python scripts/build_adventure_badges.py --check
```

维护奇遇徽记时，从 Google Fonts 官方分发取得 `MaShanZheng-Regular.ttf`，将字体路径显式
传给离线构建脚本：

```text
python scripts/build_adventure_badges.py --font <MaShanZheng-Regular.ttf 路径>
```

脚本只读取版本化名称清单、水墨母版和本地字体，不访问网络，也不会删除旧文件。字体仅用于
生成透明 PNG，不进入插件源码或运行时。构建模式会在写文件前校验字体 SHA-256 并报告缺字；
错误或不同版本的字体不会改写现有徽记。少量生僻字可由清单显式声明的项目自制透明整词蒙版
覆盖，`--check` 无需字体即可复核蒙版与正式徽记。新名称在正式徽记补齐前仍会使用本地可读
回退；异常超长或多行名称会折叠空白、限制为最多两行并受控省略，避免越出徽记。
